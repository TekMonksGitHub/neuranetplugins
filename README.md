# neuranetplugins
Neuranet Plugins

## Plugin: googlebasedocr
It is an google based ocr that usage multiple 3p tools for better and fast text extractions.

### Requirements
It has the following dependencies that needs to be install.
We can run the following commands to install them in our neuranet:
```
npm install @google-cloud/documentai
npm install sharp
npm install mammoth
sudo apt-get install mupdf-tools
```
Please, add these commands in [neuranet/install.sh.bat](https://github.com/TekMonksGitHub/neuranet/blob/main/install.sh.bat)
